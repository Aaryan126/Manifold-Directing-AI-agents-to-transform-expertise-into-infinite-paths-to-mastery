## Confirmed Architecture Decisions

*(Record finalized architecture choices here with a one-line rationale and date. This section is the record `AGENTS.md` uses to keep `prd.md` Section 8 in sync if the real stack diverges from the recommendation.)*

- 2026-08-02: Interactive agent inference is provider-routed instead of universally OpenAI. Agnes 2.5 Flash is the verified primary provider for Course Director's bounded graph-edit planning, grounded Teacher Command Center dashboard synthesis, and Learning Assistant's allowlisted intent classification. The originally planned Agnes 1.5 Flash classifier was rejected after two real calls returned Agnes `503 model_not_found` / “No available channel”; Agnes's public catalog confirms both models share `/v1/chat/completions`, so this is an account/provider-availability limitation rather than a request-shape issue. OpenAI GPT-5.4 remains responsible for high-stakes course compilation/generation, grading-adjacent content, document enrichment, and the configured fallback path. Deterministic learner routing remains model-free. All Agnes outputs are locally Pydantic-validated, Course Director mutations still become independent private `Accept / Edit / Dismiss` proposals, and publication remains the sole learner-facing boundary.
- 2026-08-02: A published Blueprint Live decision trace may resolve its final signal-linked proposal from the course's current working revision only when that revision is the published revision's direct child and the specialist task stores the exact dashboard `signal_id`. This makes a real private proposal visible at the end of the persisted evidence chain without applying it to Live, publishing it, or weakening `Accept / Edit / Dismiss`; Design traces remain scoped to their selected working revision.
- 2026-08-01: The YAML-scoped Business 101 recording course may project an accepted Course Director working revision directly inside the current Live neighborhood for the remainder of that browser session. The header and canvas explicitly label this as a `Private preview`; the active-to-working handoff matches nodes by stable logical identity, preserves every surviving node's exact painted coordinates and the current camera, and translates only genuinely new nodes relative to the focal anchor. Closing focus reveals the same working projection in the whole Blueprint, while reload/publication clears it. The active revision and every learner remain unchanged until explicit publication.
- 2026-07-31: Dense source-less lecture Blueprints use the original hierarchy-first ELK layout with independent topic → concept → teaching/check subtrees, followed only by whole-component whitespace compaction when no instructor-saved positions exist. The compactor translates each connected hierarchy group as one rigid block, so it removes ELK's arbitrary gaps without changing internal offsets, relationships, ranks, or semantic assessment edges. This explicitly supersedes the same-day invisible common-root and per-branch rewrite experiments. Course Flow independently retains its mixed saved/default position collision resolution so newly added lecture cards cannot overlap older positioned cards.
