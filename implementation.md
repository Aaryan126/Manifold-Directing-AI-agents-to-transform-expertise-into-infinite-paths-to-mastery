## Confirmed Architecture Decisions

*(Record finalized architecture choices here with a one-line rationale and date. This section is the record `AGENTS.md` uses to keep `prd.md` Section 8 in sync if the real stack diverges from the recommendation.)*

- 2026-07-11: LLM provider/model is OpenAI GPT-5.4 for all LLM-powered agents (segmentation, concept-graph building, clip extraction/classification, assessment generation, and dashboard diagnosis) so the project uses one consistent reasoning model across the AI pipeline.
- 2026-07-11: Graph storage is Postgres adjacency tables with DAG validation and recursive CTE traversal, behind a graph repository/service boundary so a future move to a dedicated graph DB is not invasive.
- 2026-07-11: ASR starts with OpenAI transcription behind a strict provider abstraction so pipeline code does not depend directly on one vendor's API shape.
- 2026-07-11 (implemented 2026-07-12): Video delivery is Mux for production, with a local adapter for development and CI. The implemented provider uses Mux Direct Uploads, polls asset creation, persists public playback IDs, reports/enforces the 10-video Free Plan cap, and remains selected only when `VIDEO_PROVIDER=mux` with credentials.
- 2026-07-12 (entry flow revised 2026-07-21): Development identity is an explicitly non-production user context with persisted instructor/learner roles. A fixed-credential development login now selects that context and routes into the matching Course OS; real password storage, signed sessions, recovery, account administration, and production authentication remain deferred.
- 2026-07-12: Production UI foundation is Tailwind CSS v4 plus shadcn/ui Nova with Base UI primitives, Lucide icons, self-hosted Instrument Sans/Source Serif 4, and semantic OKLCH design tokens. This supports the approved staged redesign while keeping component source local and auditable.
- 2026-07-21: Agent orchestration will use a durable Postgres-backed task queue and an in-process FastAPI worker with leases, retries, and restart recovery. This keeps the current Render/Neon deployment topology while moving generation ownership out of the browser.
- 2026-07-21: Published-course editing will use versioned working revisions with stable logical artifact identities. Publishing an update preserves completed learner work and maps future routing onto the new revision rather than mutating learner history.
- 2026-07-21: Course intelligence remains deterministic and evidence-first, while GPT-5.4 may explain evidence and prepare typed changes. Course Director is the single conversational coordinator; persisted Learning Analyst, Curriculum Architect, Clip Editor, and Assessment Designer activity makes specialist work visible without creating competing chat surfaces.
- 2026-07-21: The cross-course dashboard assistant uses deterministic persisted-evidence retrieval followed by GPT-5.4 structured synthesis with validated evidence IDs. The model may classify and target a requested change, but execution still creates only a private Course Director proposal; a grounded local adapter exists for tests and environments without an API key.
- 2026-07-21: Supplemental PDF/PPTX material uses revision-aware Postgres source records, page/slide extraction and citations, PostgreSQL full-text retrieval, and selective GPT-5.4 vision analysis for image/diagram-heavy pages. Documents default to private AI context and require explicit review plus publication before learner visibility.
- 2026-07-22: The Phase 11 Blueprint remains on React Flow and adds ELK.js only for visible-subgraph auto-layout. The existing Postgres adjacency model remains authoritative; no graph database, embedded n8n/H5P runtime, or Bayesian Knowledge Tracing dependency is introduced. Mastery stays evidence-first until real calibration data justifies a probabilistic model.
- 2026-07-22: Adaptive sequencing is explicit and revisioned through `concepts.sequence_rank`; prerequisite eligibility is a hard constraint, instructor sequence breaks eligible ties, and learner evidence controls remediation or reinforcement. Questions gain explicit many-to-many concept coverage and each routed attempt emits an immutable route event.
- 2026-07-22: The primary Blueprint uses deterministic topic swimlanes for whole-course comprehension, bounded topic/concept focus for artifact work, and a concept-only ELK dependency lens. The previous free-form all-artifact graph remains fully functional as `Old Blueprint`; structured layout never overwrites its persisted positions.
